MINHA DIETA — PWA OFFLINE
1. Publicado via GitHub Pages.
2. Abra a URL no Android/Chrome e use “Adicionar à tela inicial / Instalar app”.
3. Após o primeiro carregamento, o app funciona offline.
4. Os registros ficam apenas no aparelho (localStorage). Use Exportar backup regularmente.
5. Horários podem ser alterados em Configurações.
IMPORTANTE: navegadores/PWAs não garantem notificações agendadas quando o aplicativo está totalmente fechado sem um serviço push/servidor.
